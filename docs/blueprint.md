# **App Name**: PixelCanvas Portfolio

## Core Features:

- Developer Profile & Bio: A dedicated section to display the developer's experience, bio, key skills, and contact information.
- Project Showcase: An organized display of past projects, including descriptions, technologies used, and links to live demos or repositories.
- Responsive Design Framework: Ensures the portfolio is fully responsive and visually appealing across various devices and screen sizes.
- Skill & Technology Stack Display: A dynamic section to highlight and categorize the developer's technical skills and proficiency levels.
- Interactive Contact Form: A straightforward form allowing visitors to send messages directly to the developer, powered by a backend service to send emails.
- AI-Powered Cover Letter Assistant Tool: An interactive tool where users (or the developer) can input a job description, and the AI suggests tailored cover letter snippets based on the portfolio's project and skill data.

## Style Guidelines:

- Primary Color: Professional and calm blue (#0C76D1), symbolizing reliability and innovation, suitable for calls to action and prominent elements.
- Background Color: A subtle, desaturated cool grey-blue (#EDF4F8) that provides a clean, unobtrusive canvas.
- Accent Color: A fresh, vibrant aqua (#61DBDB), providing a clear contrast and drawing attention to interactive components and highlights.
- Headline and Body Font: 'Inter' (sans-serif) for its modern, clean, and highly legible appearance, aligning with 'clean code' and 'UI consistency'.
- Utilize a consistent set of minimalist, vector-based line icons to maintain a clean and professional aesthetic. Icons should complement descriptions without overpowering content.
- Implement a spacious, modular grid-based layout with clear content hierarchy. Emphasize whitespace to enhance readability and a professional, uncluttered feel. Mobile-first design principles will guide component arrangement.
- Incorporate subtle, performance-optimized animations for element transitions, hover states, and dynamic content loading to improve user experience without distractions. Examples include fade-ins and smooth scrolls.
